Central thesis

การตัดสินใจเกิดจากปฏิสัมพันธ์ระหว่างความคิดที่ผุดขึ้นรวดเร็วโดยอัตโนมัติ กับการคิดที่ช้ากว่าและใช้ความพยายาม ประเด็นสำคัญคือรู้ว่าเมื่อไร intuition เชื่อถือได้ และเมื่อไรควรหยุดตรวจสอบมัน

03
Core ideas

Bias ไม่ได้แปลว่า “คนโง่”

ข้อผิดพลาดหลายแบบเป็นผลข้างเคียงของเครื่องมือทางความคิดที่ปกติแล้วมีประโยชน์

WYSIATI: เราสร้างเรื่องจากสิ่งที่อยู่ตรงหน้าและให้น้ำหนักสิ่งที่หายไปน้อยเกินไป

Substitution: เมื่อคำถามยาก สมองอาจตอบคำถามที่ง่ายกว่าโดยไม่รู้ตัว

Anchoring: จุดเริ่มต้นสามารถดึงประมาณการของเรา แม้ไม่ควรมีน้ำหนักมากนัก

Availability: สิ่งที่นึกออกง่ายรู้สึกเหมือนเกิดบ่อยหรือสำคัญกว่า

Base-rate neglect: เรื่องเฉพาะหน้ามักแย่งความสนใจจากสถิติพื้นฐาน

Use itถามว่า “ข้อมูลอะไรที่ไม่ได้อยู่ตรงหน้า?” ไม่ใช่เพียง “ฉันคิดอะไร?”
04
Risk & choice

+100 และ −100 ไม่ได้รู้สึกสมมาตร

Prospect theory เสนอว่าคนประเมินผลลัพธ์เทียบกับ reference point และให้น้ำหนักความน่าจะเป็นแบบไม่เป็นเส้นตรง จึงช่วยอธิบาย certainty effect, loss aversion และ framing ในการตัดสินใจภายใต้ความเสี่ยง

Evidence noteงาน multinational replication ปี 2020 ทำซ้ำ theoretical contrasts หลักของ prospect theory ได้ 12 จาก 13 ข้อ แม้บาง effect จะอ่อนลง

Mental model library

สี่โมเดลที่ควรหยิบใช้บ่อยที่สุด

Outside View / Reference Class

Core idea
เริ่มจากผลลัพธ์ของกรณีคล้ายกัน ก่อนปรับด้วยข้อมูลเฉพาะเคส
Origin
แนวคิดที่ Kahneman พัฒนาร่วมกับ Amos Tversky ในงานเรื่อง prediction และ planning
Use when
forecast, project timeline, budget, new business
How
กำหนด reference class → หา distribution → วางเคสของเราเทียบ distribution → ปรับเฉพาะเมื่อมี evidence
Limitation
reference class ที่เลือกผิดสามารถสร้าง false precision ได้

Regression to the Mean

Core idea
ผลลัพธ์ที่ extreme มักตามด้วยผลที่ใกล้ค่าเฉลี่ยขึ้น แม้ไม่มี intervention ใดเป็นสาเหตุ
Use when
ประเมิน performance, coaching, sales spikes, investment results
Trap
แต่ง causal story ให้การกลับสู่ค่าเฉลี่ย เช่น คิดว่าการตำหนิ “ได้ผล” เพราะผลงานหลังวันที่แย่มักดีขึ้นอยู่แล้ว
LOSSESGAINSREFERENCE POINT

Conceptual value-function sketch: outcomes are evaluated relative to a reference point; the losses side is represented as steeper. Diagram is explanatory, not a fitted empirical curve.

Loss Aversion

Core idea
การสูญเสียเทียบ reference point สามารถมีอิทธิพลต่อการเลือกมากกว่ากำไรที่เทียบเคียงกัน
Use when
negotiation, pricing, portfolio changes, status quo decisions
Limitation
อย่าใช้เป็นคำอธิบายสำเร็จรูปกับทุกพฤติกรรม; magnitude และแม้แต่การเกิด effect ขึ้นกับบริบท

Pre-mortem

Core idea
สมมติล่วงหน้าว่าแผนล้มเหลว แล้วให้ทีมอธิบายว่าเกิดอะไรขึ้น
Use when
ทีมเริ่ม converge กับ narrative เดียวเร็วเกินไป
How
future failure → independent reasons → cluster risks → mitigation / trigger
Attribution
เทคนิค pre-mortem มาจาก Gary Klein; Kahneman สนับสนุนการใช้ ไม่ใช่ผู้คิดค้น
Bookworms ruleทุก mental model ต้องระบุ origin และ limitation เพื่อไม่ให้เครื่องมือภายนอกถูกทำให้ดูเหมือนเป็นของผู้เขียน
อ่านต่อเมื่อ: ต้องการเปลี่ยน models เหล่านี้เป็นพฤติกรรมที่ทำได้ในงานและชีวิตจริง

Decision Slow-Down

ใช้เมื่อไร: ก่อนการตัดสินใจผลกระทบสูงและย้อนกลับยาก   ทำไปทำไม: เพื่อเปิดข้อมูลที่ narrative แรกบดบัง   ผลลัพธ์: decision record ที่ตรวจย้อนหลังได้

01 · Capture

เขียนคำตอบแรกและ confidence ก่อนวิเคราะห์เพิ่ม

02 · Challenge

03 · Re-decide

ให้ estimate ใหม่และระบุว่าอะไรทำให้เปลี่ยนหรือไม่เปลี่ยนใจ

Detailed worked example

ทีมกำลังอนุมัติโครงการที่ทุกคน “รู้สึกว่าต้องเวิร์ก”

1 · Intuitionบันทึก initial view ก่อนประชุม
2 · Base rateหา reference class
3 · Challengepre-mortem / missing evidence
4 · Reframegain ↔ loss / alternatives
5 · Recorddecision + forecast + trigger
Situationทีมเสนอผลิตภัณฑ์ใหม่ Forecast บอกว่าจะคืนทุนใน 18 เดือน ทุกคนชอบ concept และลูกค้ากลุ่มทดลองตอบรับดี
Diagnosisข้อมูลทั้งหมดเป็น inside view: ความเก่งของทีม, feedback ที่ vivid และแผนที่ดู coherent ยังไม่มี base rate ของผลิตภัณฑ์ประเภทเดียวกัน
FrameworkOutside View + Pre-mortem + Decision Record
Analysisหาโครงการคล้ายกัน 20–30 เคส: median time-to-break-even, failure rate และสาเหตุหลัก จากนั้นให้สมาชิกแต่ละคนสมมติว่าโครงการนี้ล้มเหลวใน 24 เดือนและเขียนสาเหตุโดยอิสระ
Decisionแทนที่จะอนุมัติ/ไม่อนุมัติจาก forecast เดิม ให้กำหนด staged investment พร้อม milestones และ kill criteria ที่ตกลงกันก่อน
Actionบันทึก forecast ทั้ง base case และ outside-view case พร้อม probability estimate และเงื่อนไขที่จะทำให้เพิ่ม/หยุดเงินลงทุน
Outcomeกระบวนการไม่ได้รับประกันว่า project จะสำเร็จ แต่ลดโอกาสที่ narrative แรกจะผูกทีมไว้กับ forecast เดียว และทำให้เรียนรู้จากผลจริงได้ดีขึ้น
Bookworms synthesisตัวอย่างนี้สร้างขึ้นเพื่อสาธิตการประยุกต์ ไม่ใช่ case study จากหนังสือ
อ่านต่อเมื่อ: ต้องการตรวจว่าแนวคิดใดของหนังสือยังแข็งแรง และส่วนใดควรอ่านด้วยความระมัดระวัง

Critical review

อ่านหนังสือปี 2011 ด้วยหลักฐานที่มาทีหลัง

Relatively robust
Prospect theory

multinational replication ปี 2020 ทำซ้ำ pattern ส่วนใหญ่ของ risky-choice findings ดั้งเดิมได้

Useful model
System 1 / System 2

เป็นภาษาคิดที่ทรงพลัง แต่ไม่ควร reify เป็นสมองสองระบบ Kahneman เองเตือนว่าเป็นตัวละครสมมติ

Challenged
Ego depletion

งาน preregistered 23 labs (N=2,141) ปี 2016 ได้ d=0.04 และช่วงความเชื่อมั่นคร่อมศูนย์; multilab ปี 2021 อีกชุด (N=1,775) พบ effect ขนาดเล็ก d=0.10 ขณะที่ paradigmatic test 36 labs (N=3,531) ไม่พบผลใน confirmatory analysis จึงไม่ควรถือ limited-resource story ว่า settled

Caution
Behavioral priming

งานบางสายเผชิญ replication failures และข้อถกเถียงด้าน robustness; Kahneman เองเคยเรียกร้องให้วงการ priming รับมือปัญหานี้

Reading disciplineอย่าถือว่าทุก effect ที่ถูกเล่าในหนังสือมีสถานะหลักฐานเท่ากัน
